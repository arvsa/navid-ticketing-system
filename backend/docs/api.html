School Ticketing API

Branches, people and groups; tickets, actions, reports and events; work and approvals; comments, files, notifications, a dashboard and exports.

Getting started

  • Base URL: http://127.0.0.1:8080/api
  • Sign in with POST /api/auth/login. It sets an HttpOnly cookie, sid; send it with every request.
  • Every non-GET request must also send Origin: http://localhost:5173 (the frontend's address), or you get 403 origin_mismatch.
  • The machine-readable version of this page is /api/openapi.json.
# Sign in (the cookie is saved in cookies.txt)
curl -c cookies.txt -X POST http://127.0.0.1:8080/api/auth/login \
  -H 'Origin: http://localhost:5173' -H 'Content-Type: application/json' \
  -d '{"email": "member1@north.demo.school", "password": "demo-password"}'

# Then send the cookie with -b
curl -b cookies.txt http://127.0.0.1:8080/api/me

Conventions

  • JSON in and out. Times are RFC 3339 in UTC, e.g. 2026-10-20T09:00:00Z.
  • IDs are UUIDs. Issues also have a number, shown as ISS-42.
  • Lists are paged: ?limit=50 (max 200). If the response has a next_cursor, pass it as ?after=... for the next page.
  • Edits are versioned: send the version you last saw. If someone changed it meanwhile you get 409 version_conflict; reload and retry.
  • 404 means "not found or not yours to see"; the API never reveals that a private issue exists.
  • Errors always look like {"error": {"code": "...", "message": "..."}}. Branch on code.

Live updates

GET /api/stream is a Server-Sent Events stream. Events carry only IDs, for example {"kind": "issue_updated", "issue_id": "...", "branch_ids": ["..."]}; refetch what changed through the normal endpoints.

  • issue_created, issue_updated, work_item_updated, comment_*, report_*, rsvp_changed: refetch that issue and any list showing it.
  • notification: your inbox changed; refetch the unread count.
  • permissions_changed, member_changed, group_changed, branch_changed: refetch /api/me and branch data.
  • resync: events may have been missed; refetch everything. session_ended: sign in again.

Debounce refetches to at most once every 2 seconds, and refetch everything after reconnecting.
